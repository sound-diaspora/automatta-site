AutoMatta Privacy Policy

Effective: September 28, 2026

Scope

AutoMatta is a private app used only by its owner, Chad Matta, with his own Google account. This policy explains how AutoMatta handles Google user data.

Data accessed

With the owner's consent, AutoMatta accesses only the owner's own data in these Google services:

  • Gmail: read messages and send messages
  • Google Calendar: view and edit events
  • Google Drive: view and manage files
  • Google Docs: view and edit documents
  • Google Sheets: view and edit spreadsheets
  • Google Contacts: view contacts

How data is used

Data is used solely to provide the owner's personal assistant features on the owner's own computer: reading and organizing his email, calendar and files, and updating his own documents and spreadsheets. Data is not sold, not used for advertising, not used to train AI models, and not shared with anyone else.

Storage and security

Authorization tokens and any data the assistant saves are stored on the owner's own computer, which uses full-disk encryption. Tokens can be revoked at any time at myaccount.google.com/permissions.

Limited Use

AutoMatta's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
